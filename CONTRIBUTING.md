## Быстрый старт

```bash
git clone https://github.com/animesao/cardinal-panel.git
cd cardinal-panel
npm ci
cp .env.example .env
npm run db:migrate
npm run dev
```

Требуется **Node.js 24** (встроенный `node:sqlite`).

Подробности — в [документации по разработке](docs/DEVELOPMENT.md).

## Что нужно проверить перед коммитом

```bash
npm run lint          # относительные импорты в server/**
npm run lint:shell    # shellcheck для install.sh
npm run typecheck     # vue-tsc
npm test              # юнит-тесты
npm run build         # production-сборка
npm run test:e2e      # сквозные тесты (Playwright)
npm run test:install  # симуляция установки
npm run check:secrets # секреты в отслеживаемых файлах
```

`npm run ci` собирает основную часть (lint → typecheck → test → build) —
это ровно то, что гоняет CI.

Тесты обязательны: у изменений в `server/utils/**` и `server/api/**`
должен быть хотя бы один тест.

## Стиль кода

- **TypeScript** везде, кроме `scripts/*.mjs` (служебные скрипты).
- **Строгие типы**: `npm run typecheck` должен проходить без `any` в
  новом коде.
- **Комментарии — на русском**, объясняют *почему*, а не *что*.
- **Никаких секретов** в коде, `.env` или тестах. Проверяется
  `npm run check:secrets` и `gitleaks`.
- **Ошибки не глотать**: `catch {}` без логирования допустимо только там,
  где ошибка действительно ничего не меняет, и тогда нужен комментарий
  почему.

## Коммиты и ветки

Ветки: `feature/*`, `fix/*`, `docs/*`.

Сообщения коммитов — в стиле проекта:

```
feat(panel): описание изменения
fix(panel): что именно сломано и как исправлено
docs(panel): что переписано
chore(panel): служебные изменения
test(panel): тесты
```

Текст сообщения — на русском, первая строка до 72 символов, тело —
по необходимости.

## Релиз

Релизы публикуются по тегу `vX.Y.Z` — воркфлоу собирает панель,
упаковывает и создаёт GitHub Release с артефактами и SBOM.

Версию хранит файл `VERSION`; `package.json` синхронизируется скриптом
`npm run release:version`. Подробности — в
[разработке](docs/DEVELOPMENT.md#релизный-процесс).
